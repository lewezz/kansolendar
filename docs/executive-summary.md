# Product overview

Kansolendar is a native offline macOS calendar with independent password-protected
`.kanso` files. Users choose each file's name/location and calendars; the app
opens to a create/open chooser, then decrypts only after password entry.

The new format encrypts internal content and metadata as a complete document.
Password-only portability targets Apple Silicon/macOS14+. Optional manual Apple
Passwords saving does not create biometric unlock or recovery. Idle/system/close
locking and independent windows keep sessions separate. No accounts, collection
or synchronization is implemented.

Distribution is one ad hoc signed app through GitHub, without a paid membership
or temporary development profile. First-open authorization remains a macOS concern;
a published release and clean-Mac installation are not yet verified.

See [vaults](kanso-vault-files.md), [security](security.md), [distribution](distribution.md)
and [testing](testing.md) for exact behavior and limits.
